# 台灣傳統美食台語五合一互動教具

本專案是一個網頁與手機通用的台語教學互動 App，提供五種台灣傳統美食（肉粽、礤冰、潤餅、珍奶、黑輪）的配料互動調配功能。

## 使用說明
1. **配料調配**：點擊各配料卡片上的 `+` 與 `-`，可將配料放入或移出畫布。
2. **手勢操作**：配料生成在畫布中後，可在手機或網頁上拖曳移動、使用旋轉環進行 360 度旋轉，或點擊垃圾桶刪除。
3. **語音發音**：
   - 點擊卡片配料名稱或麥克風圖示，可聆聽台語發音。
   - 本 App 具備智慧雙模式語音引擎，優先使用雲端 Google TTS 播放標準台語發音。
   - 若處於離線狀態，系統會自動轉換為「台語同音字對照表」並以本地語音合成擬真朗讀。
4. **包裝與成品**：點擊「我綁好矣 / 我搖好矣！」，即可觀看成品包裝動態並伴隨精美紙花特效。

## 技能列表
- **雙模式台語發音 (Dual-mode Taigi TTS)**：支援雲端高品質台語發音與離線同音字備援發音，解決離線教學中文配音問題。
- **響應式跨平台手勢 (Cross-platform Touch Gestures)**：支援網頁滑鼠與行動裝置 Touch 事件，流暢進行配料拖曳、旋轉與刪除。
- **動態美食畫布主題 (Dynamic Canvas Themes)**：隨小吃類別自動變更 HSL 主題配色、手繪風 SVG 畫布底圖、成品圖及搖擺掛飾吊飾。

## 核心優勢
- **離線可用性**：即便在學校或防火牆阻擋外網的環境下，仍能透過同音對照朗讀台語，保障教學不中斷。
- **高度互動性**：自由拖拉與 360 度旋轉讓學童手腦並用，增強台語學習趣味性。
- **直覺式教學設計**：圖像、拼音（台羅）與聲音三合一，完美契合本土語言教學課堂。

## 應用場景
- **本土語言（台語）課堂教學**：作為國小、國中台語課的隨堂互動教具，介紹台灣飲食文化。
- **數位自主學習**：提供學童課後自我複習台語配料詞彙的趣味 App。
- **文化推廣活動**：在台灣文化節或飲食推廣活動中作展示與互動。

## Google Blogger 部署與防亂碼注意事項
本互動教具提供專門複製至 Google Blogger 運作的獨立發佈檔 [blogger_version.html](file:///c:/Users/tu-hs/OneDrive/文件/2022_0308_MASA/2022-0708/Projects_antigravity/台文教學互動app/blogger_version.html)。在後續維護或修改此檔案時，請務必遵循以下開發規範，以避免部落格端解析錯誤導致代碼失效、版面混亂或標點圖案亂碼：

1. **避免 JavaScript 代碼中的 HTML 敏感符號被轉義**：
   Google Blogger 的 XML 範本引擎會將內嵌 JavaScript（`<script>`）內的所有 XML/HTML 敏感符號（如 `&`、`<`、`>`）轉義為實體字元（如 `&amp;`、`&lt;`），造成腳本語法錯誤。
   * **規範**：所有 `<script>` 區塊內部代碼的首尾，必須以 `//<![CDATA[` 與 `//]]>` 註解包裹保護，指示解析器忽略其內部的 XML 解析。

2. **防止全形標點符號、台羅音標與 Emoji 表情符號被轉換為實體字串 (亂碼)**：
   Blogger 會將腳本字串中的所有全形標點符號（如 `！`、`，`、`：` 等）、台羅結合音標（如 `̍`）以及 Emoji 表情符號（如 ⚫, ⬜, ⚪）自動轉換成十進位字元實體（如 `&#65281;`、`&#9899;`）。由於前端多以 `.innerText` 方式為欄位賦值，這會導致網頁直接顯示實體代碼（如按鈕顯示為「我綁好矣&#65281;」，卡片圖案顯示為「&#9899;」）。
   * **規範**：Blogger 專用版發佈檔腳本區塊內的所有**非 ASCII 字元**（字元編碼大於 127 者，包含中文漢字、台語聲調與 Emoji）應全面進行 **Unicode 轉義編譯**（編譯成 `\uXXXX` 或 `\u{XXXXX}`，例如將 `⚫` 轉為 `\u26AB`，將 `中` 轉為 `\u4e2d`）。由於轉義後皆由 ASCII 字元組成，Blogger 解析器將完全不會對其進行任何篡改，並由瀏覽器在執行期原生還原正確字元。

3. **記事本複製亂碼預防 (UTF-8 with BOM)**：
   為了防止 Windows 使用者以內建「記事本」等工具開啟發佈檔進行拷貝時，因系統預設語系（ANSI/CP950）錯誤判斷導致貼到 Blogger 後產生整體亂碼。
   * **規範**：發佈檔 `blogger_version.html` 必須存檔為 **UTF-8 with BOM (utf-8-sig)** 編碼，保證各種編輯器能正確識別 UTF-8。
